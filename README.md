## О проекте

Цель проекта — подготовить полный и качественный русский перевод **New Love Plus+** для **Nintendo 3DS**.

Сейчас репозиторий находится на начальном этапе. Файлы перевода, подробное описание, инструкции и другая информация будут добавляться постепенно.

## Важная информация

Это неофициальный фанатский проект. Репозиторий не предназначен для распространения образа игры или других защищённых авторским правом файлов. Для использования будущего патча потребуется собственная копия игры.

**New Love Plus+** и связанные с ней материалы принадлежат их правообладателям.
