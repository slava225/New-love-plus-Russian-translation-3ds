# New Love Plus+ RU v0.1.1-beta

Исправление вероятной причины чёрного экрана при запуске установленной японской CIA, в том числе на европейских Nintendo 3DS.

## Что исправлено

- из пакета удалён устаревший внешний `code.bin`;
- сохранён небольшой `code.ips`, применяющий нужное изменение к исполняемому файлу самой игры;
- уточнена установка на EUR-консоль и проверка Title ID для CIA.

Текст, графика и сохранения игры по сравнению с v0.1.0-beta не изменялись.

## Важно при обновлении

Сначала полностью удалите или переименуйте старую папку:

```text
SD:/luma/titles/00040000000F4E00
```

Затем скопируйте новую папку из `SD_ROOT`. Не объединяйте версии: оставшийся от v0.1.0-beta файл `code.bin` может снова вызвать чёрный экран.

Регион консоли может быть EUR, USA или JPN. Нужна чистая японская версия игры на картридже или из CIA с Title ID `00040000000F4E00`. Полная инструкция находится в [docs/INSTALLATION.md](https://github.com/slava225/New-love-plus-Russian-translation-3ds/blob/main/docs/INSTALLATION.md).
