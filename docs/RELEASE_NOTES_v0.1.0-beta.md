# New Love Plus+ RU v0.1.0-beta

Первый публичный тестовый выпуск русского перевода для японской версии New Love Plus+ с Title ID `00040000000F4E00`.

## Что входит

- готовая структура `SD_ROOT` для Luma3DS LayeredFS;
- русский текст 578 сценарных контейнеров;
- системный и интерфейсный текст;
- переведённая графика меню, профиля, почты, заданий, часов и дат;
- последние исправления интерфейса почты и кнопок возврата;
- инструкция и контрольные суммы всех файлов.

Архив устанавливается напрямую, xdelta не нужен. Скопируйте содержимое `SD_ROOT` в корень SD-карты и включите `Enable game patching` в Luma3DS. Полная инструкция находится в [docs/INSTALLATION.md](https://github.com/slava225/New-love-plus-Russian-translation-3ds/blob/main/docs/INSTALLATION.md).

Это beta-версия: ручная сверка с японским оригиналом и полное прохождение продолжаются. Об ошибках можно сообщить через [готовые формы Issues](https://github.com/slava225/New-love-plus-Russian-translation-3ds/issues/new/choose).
