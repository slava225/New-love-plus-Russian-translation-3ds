# New Love Plus+ RU v0.1.3-beta

Исправление вылета ARM11 сразу после запуска полной русской сборки на реальной Nintendo 3DS.

## Что исправлено

- в `textresource_config.trb` увеличен лимит загрузки системного текста с `0x13E7E4` до `0x1BE7E4`;
- полный русский `textresource_jpn.trb` размером `0x1BD7E4` теперь полностью помещается в выделенный буфер;
- исправление проверено на реальной Nintendo 3DS европейского региона с установленной японской CIA.

Сценарии, графика и содержимое перевода не менялись. Исправлен только размер буфера, необходимый для уже включённой в релиз полной русской таблицы.

## Важно при обновлении

Полностью удалите или переименуйте старую папку:

```text
SD:/luma/titles/00040000000F4E00
```

После этого скопируйте новую папку из `SD_ROOT`. Не объединяйте файлы разных версий.
