# New Love Plus+ RU v0.1.2-beta

Исправление чёрного экрана, возникающего сразу после запуска японской CIA.

## Что изменено

- возвращён проверенный `code.bin`, с которым патч ранее запускался на реальной Nintendo 3DS;
- оставлен `code.ips`, содержащий ту же 8-байтную правку `extdata:` → `rom:`;
- проверен ранний стартовый пакет `90` внутри `img.bin`: он побайтно совпадает с рабочей аппаратной версией размером 29 232 байта;
- текст, графика и сохранения игры не изменялись.

## Важно при обновлении

Полностью удалите или переименуйте старую папку:

```text
SD:/luma/titles/00040000000F4E00
```

После этого скопируйте новую папку из `SD_ROOT`. Не объединяйте файлы разных версий.

Регион консоли может быть EUR, USA или JPN. Игра должна иметь японский Title ID `00040000000F4E00`.
