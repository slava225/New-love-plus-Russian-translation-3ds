# История изменений

Все заметные изменения проекта будут перечисляться в этом файле.

## v0.1.1-beta — 2026-08-28

Исправление запуска установленной японской CIA, в том числе на европейских консолях.

### Исправлено

- удалён устаревший внешний `code.bin`, который мог вызывать чёрный экран на части конфигураций;
- оставлен небольшой `code.ips`, который применяет нужное изменение к исполняемому файлу самой игры;
- уточнена установка на EUR-консоль и проверка Title ID для CIA;
- добавлено обязательное удаление файлов v0.1.0-beta перед обновлением.

Текст, графика и сохранения игры по сравнению с v0.1.0-beta не изменялись.

## v0.1.0-beta — 2026-08-27

Первый публичный тестовый выпуск русского перевода.

### Добавлено

- готовый RAR для установки через Luma3DS LayeredFS без xdelta;
- русский текст для 578 сценарных контейнеров;
- системный и интерфейсный текст;
- переведённые графические элементы меню, профиля, почты, заданий, часов и дат;
- инструкция по установке, обновлению и удалению;
- контрольные суммы всех файлов релиза;
- формы GitHub Issues для ошибок перевода и проблем установки.

### Исправлено

- ряд проблем с компоновкой и шрифтами;
- найденные непереведённые состояния кнопок возврата;
- последние выявленные варианты интерфейса почты.

### Известные ограничения

- ручная сверка с японским оригиналом продолжается;
- полное прохождение всех веток ещё не завершено;
- возможны остаточные непереведённые изображения и переполнение текста.
